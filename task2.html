Introduction

This project presents a real-time monitoring system designed to improve both safety and well-being in environments such as classrooms, offices, and workplaces.

Key Features

  • Real-time monitoring of individuals in various environments.
  • Detection of potential safety hazards and well-being issues.
  • Integration with existing security systems for enhanced safety.
  • Data analytics and reporting for informed decision-making.

Applications

  1. Classroom Monitoring: Ensuring student safety and engagement.
  2. Office Surveillance: Enhancing workplace security and productivity.
  3. Public Spaces: Monitoring for safety in parks, malls, and other public areas.
